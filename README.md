Portfolio - Anicet YAO

Site portfolio personnel présentant mon parcours de géomaticien et mes projets en SIG, cartographie, télédétection et développement WebSIG.

Site en ligne : https://anicetyao225.github.io/porfolio/ Version anglaise : https://anicetyao225.github.io/porfolio/en/

- À propos

Ce portfolio réunit mon parcours professionnel, mes projets techniques (WebSIG, automatisation de traitements géospatiaux avec Python et FME, analyse de données) et mes compétences. Il est disponible en français et en anglais, avec un contenu maintenu à jour au fil de mes expériences.

- Fonctionnalités
  
Site bilingue (FR/EN), avec balises hreflang pour le référencement
Section Projets filtrable par catégorie
Lightbox pour la visualisation des projets sans lien externe
Section Parcours en deux colonnes (Formation / Expérience), avec un slider sur la partie Expérience
Mise en surbrillance du lien de navigation actif au scroll
Animations légères au scroll
Formulaire de contact fonctionnel, avec envoi réel des messages et retour de statut
Design responsive
Pas de framework : HTML, CSS et JavaScript natifs

- Stack technique
HTML5
CSS3 (variables custom, Grid, Flexbox)
JavaScript (vanilla, ES6+)
Ionicons pour les icônes
FormSubmit pour la gestion du formulaire de contact
Hébergement via GitHub Pages
GoatCounter pour les statistiques de fréquentation (léger, sans tracking intrusif)
